# Windows Support Guide

## Overview

`find_dups` fully supports Windows with native implementations for Go, Rust, C++, and JavaScript (Node.js/Bun). This guide covers Windows-specific setup and usage.

## Prerequisites

### Go Implementation
```powershell
# Install Go from https://golang.org/dl/
# Or use winget
winget install GoLang.Go

# Verify installation
go version
```

### Rust Implementation
```powershell
# Install Rust from https://rustup.rs/
# Or use winget
winget install Rustlang.Rust.MSVC

# Verify installation
rustc --version
cargo --version
```

### Python Implementation
```powershell
# Install Python from https://python.org/
# Or use winget
winget install Python.Python.3.12

# Verify installation
python --version
```

### C++ Implementation
```powershell
# Install Visual Studio Build Tools
# Download from: https://visualstudio.microsoft.com/downloads/
# Select "C++ build tools"

# Or use MinGW-w64
# Download from: https://www.mingw-w64.org/

# Verify installation
g++ --version
```

### OpenSSL (for C++)
```powershell
# Install OpenSSL for Windows
# Download from: https://slproweb.com/products/Win32OpenSSL.html
# Or use vcpkg
vcpkg install openssl:x64-windows
```

## Building on Windows

### Go

```powershell
cd find_dups_go
go build -o find_dups.exe find_dups.go
```

### Rust

```powershell
cd find_dups_rust
cargo build --release
# Binary: target\release\find_dups.exe
```

### Python

No build required - just run:
```powershell
python find_dups_python\find_dups.py C:\path\to\scan
```

### C++

**Using Visual Studio:**
```powershell
cd find_dups_cp

# Using MSVC
cl /EHsc /O2 /std:c++17 /I"C:\Program Files\OpenSSL-Win64\include" ^
   /LIBPATH:"C:\Program Files\OpenSSL-Win64\lib" ^
   find_dups.cpp /Fe:find_dups_cpp.exe libcrypto.lib libssl.lib ws2_32.lib
```

**Using MinGW:**
```powershell
cd find_dups_cp

g++ -std=c++17 -O3 -static ^
    -I"C:\OpenSSL-Win64\include" ^
    -L"C:\OpenSSL-Win64\lib" ^
    find_dups.cpp -o find_dups_cpp.exe -lcrypto -lws2_32
```

## Usage on Windows

### Basic Usage

```powershell
# Scan a directory
.\find_dups.exe C:\Users\YourName\Documents

# Scan multiple directories
.\find_dups.exe C:\Users\YourName\Documents D:\Backup E:\Photos

# Python version
python find_dups_python\find_dups.py C:\Users\YourName\Documents
```

### Path Formats

Windows supports multiple path formats:

```powershell
# Traditional backslash paths
.\find_dups.exe C:\Users\YourName\Documents

# Forward slashes (also work)
.\find_dups.exe C:/Users/YourName/Documents

# UNC paths for network shares
.\find_dups.exe \\server\share\folder

# Relative paths
.\find_dups.exe ..\..\Documents

# Mixed
.\find_dups.exe C:\Users\YourName\Documents D:\Backup ..\..\Projects
```

### Running as Administrator

Some directories may require elevated privileges:

```powershell
# Open PowerShell as Administrator
# Then run
.\find_dups.exe C:\Windows\System32
```

## Output Files on Windows

Output files are generated with Windows-appropriate names:

```
duplicates_go.csv       (or _cpp, _py, _rs, _js)
sort_dup_go.csv
analytics_go.json
duprm_go.sh             # Shell script (not for Windows)
duprm_go.bat            # Batch script (Windows-specific)
```

### Deletion Script (Windows)

The tool generates a **batch script** for Windows:

```batch
@echo off
REM Generated by find_dups
REM Review before executing!

del /F /Q "C:\path\to\duplicate1.txt"
del /F /Q "D:\backup\duplicate2.txt"

echo Deletion complete.
```

**⚠️ ALWAYS REVIEW BEFORE EXECUTION:**

```powershell
# Review the batch script
Get-Content duprm_go.bat | less

# Execute if satisfied
.\duprm_go.bat
```

## PowerShell Integration

### Scan and Analyze

```powershell
# Run scan
.\find_dups.exe C:\Users\YourName\Documents

# Parse analytics
$analytics = Get-Content analytics_go.json | ConvertFrom-Json

# View summary
$analytics.summary

# View by category
$analytics.by_category.PSObject.Properties

# Calculate recoverable space
$recoverableGB = $analytics.summary.recoverable_bytes / 1GB
Write-Host "Recoverable: $recoverableGB GB"
```

### Filter Results

```powershell
# Find large duplicates
Import-Csv duplicates_go.csv | Where-Object { [int]$_.Size -gt 1MB }

# Find duplicate images
Import-Csv duplicates_go.csv | Where-Object { $_.Path -match '\.(jpg|png|gif)$' }

# Group by extension
Import-Csv duplicates_go.csv | Group-Object { [System.IO.Path]::GetExtension($_.Path) }
```

## Performance on Windows

### Antivirus Impact

Windows Defender may slow down scanning:

```powershell
# Temporarily exclude scan directory (CAUTION!)
Add-MpPreference -ExclusionPath "C:\path\to\scan"

# Run find_dups
.\find_dups.exe C:\path\to\scan

# Remove exclusion after scan
Remove-MpPreference -ExclusionPath "C:\path\to\scan"
```

### NTFS vs ReFS

- **NTFS**: Good performance, most common
- **ReFS**: Better for large files, slightly slower for many small files
- **FAT32**: Slower, not recommended

### Recommended Implementations

| Use Case | Best Choice | Why |
|----------|-------------|-----|
| General use | **Go** | Fast, single .exe, no dependencies |
| Maximum speed | **Rust** | Fastest, small binary |
| Already have Python | **Python** | No build needed |
| Development environment | **C++** | Integrates with Visual Studio |

## Windows-Specific Considerations

### File System Features

**NTFS Alternate Data Streams (ADS):**

The tool ignores ADS - only the main data stream is hashed.

**Hard Links:**

Files linked via hard links are treated as separate files (different paths).

**Symbolic Links:**

Symbolic links are **skipped** by default to avoid double-counting.

### Path Length Limits

Windows has a 260-character path limit (MAX_PATH):

```powershell
# For long paths, use \\?\ prefix
.\find_dups.exe \\?\C:\very\long\path\...

# Or enable long path support in Windows 10+
# Requires: registry modification or Group Policy
```

### File Locks

Some files may be locked by other applications:

```powershell
# Check for locked files
# (find_dups will skip them with a warning)
```

### Permissions

```powershell
# Check if you have access
Test-Path C:\path\to\scan

# Run as Administrator if needed
# Right-click -> "Run as Administrator"
```

## Automation

### Scheduled Task

```powershell
# Create a scheduled task for weekly scans
$action = New-ScheduledTaskAction -Execute "C:\path\to\find_dups.exe" -Argument "C:\Users\YourName\Documents"
$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Sunday -At 2am
Register-ScheduledTask -TaskName "WeeklyDuplicateScan" -Action $action -Trigger $trigger
```

### Startup Script

```powershell
# Create a startup script
@"
C:\path\to\find_dups.exe C:\Users\YourName\Documents
C:\path\to\find_dups.exe D:\Backup
"@ | Out-File -FilePath "C:\Scripts\scan_duplicates.ps1"
```

## Windows Batch Scripts

Included Windows-specific scripts:

### build_all.bat
Builds all Windows implementations:

```batch
@echo off
echo Building find_dups for Windows...

REM Go
cd find_dups_go
go build -o find_dups.exe find_dups.go
cd ..

REM Rust
cd find_dups_rust

cl /EHsc /O2 /std:c++17 find_dups.cpp /Fe:find_dups_cpp.exe

echo Build complete!
```

Runs all tests on Windows:

```batch

REM Setup test data
call test_data\setup_test_data.bat

REM Run tests (implementations will check for .exe extension)
powershell -ExecutionPolicy Bypass -File tests\run_smoke_tests.ps1
```

## Cross-Platform Notes

### Path Separator

Windows accepts both `\` and `/`:

```powershell
# Both work
.\find_dups.exe C:\Users\YourName\Documents
.\find_dups.exe C:/Users/YourName/Documents
```

### Line Endings

Output files use Windows line endings (CRLF):
- CSV files: `\r\n`
- Batch scripts: `\r\n`

### Executable Extension

Windows binaries use `.exe` extension:
- `find_dups.exe`
- `find_dups_cpp.exe`
- `find_dups_go.exe`
