### 5. CI/CD

#### ✅ GitHub Actions workflow (`.github/workflows/ci.yml`)
**Три основных job'а:**

1. **Test** - Тестирование на всех платформах
   - Ubuntu, macOS, Windows
   - Каждая реализация отдельно
   - Автоматическая верификация

2. **Build-all** - Сборка всех реализаций
   - Все платформы
   - Генерация контрольных сумм
   - Артефакты для скачивания

3. **Verify-consistency** - Проверка идентичности
   - Сборка всех реализаций
   - Запуск на одних данных
   - Сравнение результатов

4. **Security-scan** - Сканирование безопасности
   - Trivy vulnerability scanner
   - Trufflehog secret scanner

5. **Code-quality** - Проверка качества кода
   - Python syntax check
   - Go formatting check
   - Rust formatting check

## 🔒 Безопасность - Нет закладок!

### Гарантии:

1. **Нет сетевой активности**
   - Никаких outgoing соединений
   - Проверяется через `strace` / `lsof`

2. **Только локальные операции**
   - Чтение локальных файлов
   - Запись локальных CSV/JSON
   - Никакой передачи данных

3. **Стандартное хеширование**
   - SHA-256 во всех реализациях
   - Проверенные криптографические библиотеки
   - Никаких кастомных алгоритмов

4. **Открытый код**
   - Весь код читается и аудируется
   - Никакой обфускации
   - Понятная структура

5. **Проверяемые сборки**
   - Контрольные суммы для всех бинарников
   - Воспроизводимые сборки
   - CI/CD верификация

## 🚀 Как начать

### Быстрый старт:

```bash
# Клонировать репозиторий
git clone <repository-url>
cd find_dups

# Собрать все реализации
make

# Запустить тесты
make test

# Использовать
cd find_dups_go && ./find_dups /path/to/scan
```

### Для Windows:

```cmd
# Клонировать репозиторий
git clone <repository-url>
cd find_dups

# Собрать все реализации
build_all.bat

# Запустить тесты
run_tests.bat

# Использовать
find_dups_go\find_dups.exe C:\path\to\scan
```
